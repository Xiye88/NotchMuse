纯本地处理说明

本页面所有格式转换与时间轴计算均由你浏览器内的本地脚本完成，不会向任何服务器上传歌词文件，也不会调用第三方搜词接口。

  • LRC 转 SRT：支持标准 [mm:ss.xx] 与毫秒级 [mm:ss.xxx] 标签，自动展开同行多时间戳并按时间排序，支持自定义末句停留秒数。
  • LRC 时间轴偏移：支持按毫秒（ms）或秒（s）正向延后或负向提前，保留 [ti:]、[ar:] 等元信息；负时间戳自动归零至 [00:00.00]。
  • SRT 转 LRC 与纯文本提取：可将剪辑软件导出的 .srt 字幕还原为 .lrc，或一键剥离时间标签得到干净的 .txt 纯文本。

常见问题

我拖入的 .lrc 或 .srt 文件会上传到服务器吗？

完全不会。文件读取、时间轴计算与导出下载全部基于浏览器原生 FileReader 与 Blob API 在本地完成。

时间轴往前移变成负数会怎么样？

工具会自动将任何小于 00:00.00 的时间戳归零钳位至 [00:00.00]，并在状态栏提示被归零的条目数量。

同行包含多个时间戳（如副歌复用）能正常转 SRT 吗？

可以。转换器会自动拆分如 [00:32.00][01:48.50]歌词 的复合时间标签，并按播放顺序生成连续编号的 SRT 字幕。

## Archive

The four root-level v0.6–v0.7.1 gate reports are indexed above and grouped in
[archive/README.md](archive/README.md). Earlier APP, LAB, MATCHER, and UX reports
remain under their owner directories and are indexed above without content
rewrites.

## Completion Report Format

Execution threads must save a Task Completion Report in the matching
subdirectory.

```md
# Task Completion Report

Task:

Status:

Priority:

## Findings

## Problems Found

## Recommended Actions

## Need PM Decision
```

Directory ownership: `app/` = `01_APP`; `benchmark/` = `03_LAB`; `matcher/` =
`05_MATCHER`; `release/` = `02_RELEASE`; `ux/` = `04_UX`; `github/` = `06_DOCS`
and repository architecture work.

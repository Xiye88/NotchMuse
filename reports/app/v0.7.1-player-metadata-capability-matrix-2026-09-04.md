# v0.7.1 Player Metadata Capability Matrix

日期：2026-09-04

## 结论

播放器脚本接口确实还有未传入 `NowPlayingTrack` 的字段，但现有接口都不直接
提供 ISRC。增加这些字段不需要改变 Matcher，不过目前没有证据证明它们能解除
真实 ambiguity，因此本轮不进入 Production。

| 字段 | Spotify 当前 | Spotify 可读未传递 | Apple Music 当前 | Apple Music 可读未传递 |
| --- | --- | --- | --- | --- |
| title / artist / album / duration | 已获取并使用 | - | 已获取并使用 | - |
| playback state / position | 已获取并使用 | - | 已获取并使用 | - |
| album artist | 未获取 | AppleScript dictionary 可读 | 未获取 | AppleScript dictionary 可读 |
| native track ID | `nil` | `id` / `spotify url` 可读 | persistent ID 已获取 | database ID 可读 |
| ISRC | 不可读 | 需 Spotify Web API | 不可读 | 需 MusicKit / catalog API 或外部映射 |
| release date / year | 不可读 | - | 未获取 | release date / year 可读 |
| disc / track number | 未获取 | 可读 | 未获取 | 可读 |
| explicit | 不可读 | - | 不可读 | - |
| version / edition | title/album 推导 hint | 无结构化字段 | title/album 推导 hint | 无结构化字段 |
| artwork | 未获取 | artwork URL 可读 | 未获取 | artwork object 可读 |

证据：

- `SpotifyReader.swift` 当前只返回 name、artist、album、duration 和 position。
- `SpotifyAdapter` 当前明确写入 `nativeTrackID: nil`、`isrc: nil`。
- Spotify 本机 scripting dictionary 声明 album artist、disc number、track
  number、id、spotify URL、artwork URL 和 popularity。
- `AppleMusicAdapter.swift` 当前读取 persistent ID，但 `isrc: nil`。
- Music.app scripting dictionary 声明 persistent ID、database ID、album artist、
  release date、year、disc/track number 和 artwork；其中 persistent ID 的稳定性是
  Music library 范围，不等于 Apple catalog ID。

## ISRC 判断

- Spotify：桌面 AppleScript 不提供 ISRC。`spotify url` 可以给出 Spotify track
  identity，但继续映射 ISRC 需要 OAuth Web API 和额外网络请求。
- Apple Music：当前 AppleScript 不提供 ISRC 或 catalog ID。persistent ID 对本机
  library 有价值，但不能直接与歌词 Provider 对齐。
- Provider：目前只有 LRCMux 已证明返回 ISRC；其他 Provider 的稳定 ID 彼此不通用。

结论：ISRC 是高价值 identity signal，但当前不是低成本端到端能力。暂不采用
Production Track Identity Bridge。

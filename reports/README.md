# NotchMuse Reports

Execution threads must save a Task Completion Report in the matching subdirectory.

Required format:

```md
# Task Completion Report

Task:

Status:

Priority:

## Findings

## Problems Found

## Recommended Actions

## Need PM Decision
```

Directories:
- `release/`: build, signing, notarization, install, runtime QA
- `ux/`: Status Bar, Notch Mode, Settings, permissions, display QA
- `benchmark/`: coverage, provider ranking, failed songs, dashboard reports
- `matcher/`: Benchmark to App optimization analysis
- `github/`: README, screenshots, demo GIF, release notes, publishing package

# NotchMuse v0.8.4 (Build 82)

## English

### Native In-App Announcements & Release History
- **In-app Updates & Announcements window**: Clicking the top announcement bar in Settings (or the Menu Bar entry) opens a native window inside NotchMuse to read announcements and version history instead of jumping to a browser.
- **Pinned bar & subtle unread dot**: The top announcement bar stays permanently visible showing the latest update and displays a subtle orange unread dot when new announcements arrive.
- **Quiet background refresh**: Automatically refreshes announcements every 6 hours and when reopening Settings so long-running sessions stay up to date.

### Instant Bilingual Release Notes & Unified Support
- **Zero-JS EN/ZH release notes switching**: Release notes inside the Sparkle update dialog default to your macOS language and switch instantly between English and Chinese.
- **Unified support email**: Feedback and support now route to `support@notchmuse.com`, with a built-in footer link inside the Updates & Announcements window.
- Includes all v0.8.3 improvements (90% lyrics match rate across Apple Music, Spotify, NetEase Cloud, and Soda Music, automatic launch update checks, and Notch/Free Floating UI polish).

### Feedback & Community

- **GitHub Issues**: https://github.com/Xiye88/NotchMuse/issues
- **Release Notes (Web)**: https://notchmuse.com/releases/v0.8.4/NotchMuse.html

## 简体中文

### 原生应用内「更新与公告」中心
- **不再跳转浏览器**：点击设置页顶部公告条（或菜单栏公告入口）改为直接打开 NotchMuse 原生「更新与公告」窗口，随时查看平台公告与历史版本记录。
- **常驻公告条 + 未读小圆点**：顶部公告条点击后不再消失，固定展示最新一条；有新公告时右侧显示橙色小圆点，点开查看后自动消除。
- **定时静默刷新**：每 6 小时及重新打开设置页时按需静默刷新公告，菜单栏长期不重启也能自动同步最新消息。

### 更新说明一键切换与统一反馈邮箱
- **更新弹窗零延迟中英切换**：Sparkle 更新弹窗按系统语言自动优先展示中文或英文，并支持零 JS 一键切换。
- **统一反馈邮箱**：反馈渠道统一升级为 `support@notchmuse.com`，并在「更新与公告」窗口底部内置直达入口。
- 完整包含 v0.8.3 全部升级（四平台歌词命中率提升至 90%、启动自动检查更新与自动下载安装开关、刘海与悬浮词条质感升级）。

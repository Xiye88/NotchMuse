原生对接 macOS 系统播控中心

NotchMuse 通过 macOS 系统级 MediaRemote / Now Playing 接口读取汽水音乐 Mac 桌面客户端的当前播放信息，无需复杂注入或第三方脚本。

开启播放后即可自动跟随切歌与播放进度，在歌词源提供逐字时间轴时也能自然同步呈现。

双模显示：黑边刘海伴侣与极简菜单栏

在配备刘海屏的 MacBook 上，可使用刘海模式让歌词贴合屏幕顶部或停靠在 Dock 上方；日常办公希望更低调时，可切换为菜单栏模式在顶部状态栏安静滚动。

两种模式均由原生 Swift 与 AppKit 构建，轻量运行，不打扰你的日常多任务工作流。

快速设置与系统权限说明

  1. 打开汽水音乐 Mac 桌面客户端并开始播放任意歌曲。
  2. 启动 NotchMuse，从顶部菜单栏图标打开设置，保持“自动检测”开启或手动选择汽水音乐。
  3. 根据屏幕与习惯选择“刘海模式”或“菜单栏模式”，并微调宽度与配色预设。
  4. 如选用菜单栏左侧布局，按 macOS 提示在“系统设置 → 隐私与安全性 → 辅助功能”中授权。

常见未识别或网络缓冲排查

若刚切歌时未显示歌词，请先打开 macOS 控制中心确认“播放中”已出现汽水音乐曲目信息。网络重连后暂停再继续播放，通常可立即恢复同步。

若曲名已更新但暂无歌词，可换一首主流歌曲验证，以区分曲库覆盖与播放识别问题。

常见问题

使用 NotchMuse 查看汽水音乐歌词需要登录账号吗？

完全不需要。NotchMuse 无需登录任何账号，不收集个人隐私，通过系统级媒体接口与公共索引匹配歌词。

为什么打开汽水音乐后状态栏没有立即显示歌词？

请确认汽水音乐正在出声播放且 macOS 控制中心的“播放中”组件已出现歌曲信息。软件捕获系统音频通道后将自动开始匹配。

外接显示器或没有刘海的 Mac 可以使用吗？

可以。软件会自动识别屏幕环境，在无刘海设备（如 Mac mini、Mac Studio 或非刘海屏幕）上可切换为菜单栏常显或桌面悬浮模式。

是否支持汽水音乐的纯音乐或即兴翻唱曲目？

若歌曲具备公开时间轴歌词，NotchMuse 均可同步显示；部分无公开时间轴的小众原声或纯音乐仅显示歌曲名与艺术家信息。

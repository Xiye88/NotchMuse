# v0.7 Matcher Experiment Gate

日期：2026-08-30

## Decision

- 小规模、离线、人工标注实验：`CONDITIONAL GO`
- 现有 frozen dataset 直接宣称 ranking 提升：`NO-GO`
- Production Matcher 修改：`NO-GO`

Track Identity Dataset v1 有 `2,568` 条失败 case，但人工标签为 `0/2,568`。
因此 confirmed false positive 不是零，而是尚未测量。

## Signal Readiness

| Signal | Gate |
| --- | --- |
| Title | Conditional Go：仅离线分层和人工标签 |
| Artist | Conditional Go：完整 artist set 真值不足 |
| Duration | Conditional Go：`974` 个 top/second pair 有双方 duration |
| Album | No-Go：candidate album 覆盖 `0/2,568` |
| Version hints | Conditional Go：只做冲突保护与审计 |
| ISRC | No-Go：双方比较覆盖 `0%` |

## Highest-Value Evidence Pools

1. Duplicate-candidate ambiguity：run 19 的 `489` 个 ambiguity case 中，
   `464` 个满足严格 title、完整 artist set、duration `<=2s` 等价；仍需人工核验
   lyric text、version 与 timing。
2. Candidate-backed metadata conflict：run 32 有 `960` 个
   `below_threshold`，适合按 title、artist、duration、version 分层标注。
3. Provider no candidate：run 32 有 `1,211` 个 `no_candidates`，其中 QQ
   `926`、Kugou `285`；这些不属于 ranking 问题，必须排除在 Matcher 实验分母外。

## Experiment Rules

- 只使用冻结 candidate set，不重新请求 Provider。
- strategy-blind 标注 `top / second / neither / uncertain`。
- 每个改变的决定都人工复核；`uncertain` 不进入准确率分母。
- confirmed false positive 必须为 `0`；出现一条立即停止。
- Album 暂不参与；version 只用于冲突保护。
- 没有独立 labeled holdout，不得进入 Production。

## Simulator Limitation

当前 `_old_selection()` 只识别 `top/second`，而 frozen rows 使用
`ambiguous_gap/below_threshold/no_candidates`；修正离线指标口径前，不能可靠
计算完整 Current Ranking delta。该限制只影响 Benchmark simulator，不影响 App。

Windows 实机演示

在 Windows 上使用 Spotify 悬浮歌词（Spotify Lyrics Overlay）

Spotify 自带的歌词界面只能在客户端内部查看，一旦切换回浏览器或编辑器就会被遮挡。NotchMuse 为 Windows 带来克制、支持点击穿透的 Spotify 桌面悬浮歌词 与任务栏歌词，切窗不中断、不抢焦点。

第 1 步

打开 Spotify 播放音乐

在 Windows 11 或 10 上照常播放 Spotify 歌曲，NotchMuse 通过系统原生 SMTC 自动读取曲目与进度。

第 2 步

切回浏览器、IDE 或游戏

最小化 Spotify，照常在 Chrome、VS Code、Figma 或无边框窗口化游戏中操作，无需分屏占位。

第 3 步

锁定悬浮歌词并开启点击穿透

固定悬浮歌词的位置后，鼠标点击可直接传到下方窗口。

常见问题

支持哪些 Windows 系统版本？

NotchMuse Windows 版面向 Windows 11 与 Windows 10（64 位），通过系统原生 SMTC 读取播放状态。

开启悬浮歌词后会影响点击浏览器或游戏吗？

不会。开启“点击穿透”和“位置锁定”后，所有鼠标操作会直接穿透歌词层作用于下方应用。

支持 MusicBee 和 foobar2000 吗？

支持。只要播放器向 Windows SMTC 输出播放信息（包括 MusicBee、foobar2000、Spotify 及浏览器标签页），均可自动同步歌词。

我在用 Mac，在哪里下载 macOS 版？

macOS 14+（Apple 芯片）正式版现已开放免费下载，请前往 NotchMuse 首页。

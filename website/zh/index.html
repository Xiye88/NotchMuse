官网隐私与统计

由你选择是否开启统计。

NotchMuse 应用不收集使用分析数据，也不上传音频。经你同意，官网使用 Google Analytics 统计访问和下载按钮点击。官网统计与应用本身相互独立。

Google Analytics 使用第一方 Cookie 统计访问、来源和下载按钮点击。下载点击事件只附带应用版本、按钮位置与页面语言，不发送歌词、曲目信息、邮箱或其他个人内容。点击不代表下载完成或安装成功。

同意之前不会启动统计。拒绝不影响下载；你可以使用下方或页脚的入口重新设置。已同意后再拒绝，将停止统计、清理本站分析 Cookie 并刷新页面，以移除已加载的统计脚本。已经发送的数据无法撤回；先前正在传输的请求可能完成。若浏览器禁用存储，选择仅在当前页面有效。

统计只覆盖已同意且未拦截的访问。你也可以在浏览器设置中清理 Cookie 和网站存储。参阅 Google 隐私政策。

安装与设置

几步即可开始使用。

NotchMuse v0.8.0 需要 macOS 14 或更新版本，以及 Apple 芯片 Mac。

  1. 下载并打开 DMG。
  2. 将 NotchMuse 拖到“应用程序”。
  3. 在“应用程序”中按住 Control 键并点按 NotchMuse，然后选择“打开”。
  4. 如果 macOS 阻止打开，请前往“系统设置”→“隐私与安全性”→“仍要打开”。
  5. 根据提示授予所需权限。

官网下载包尚未使用 Apple Developer ID 公证，macOS 首次打开时可能显示安全提示。

首次打开步骤
  1. 打开 DMG，将 NotchMuse 拖到“应用程序”。
  2. 尝试打开 NotchMuse。如果 macOS 阻止打开，请点击“完成”，不要将应用移到废纸篓。
  3. 打开“系统设置”→“隐私与安全性”，选择“仍要打开”。
  4. 按 macOS 提示完成认证，然后再次打开 NotchMuse。

常见问题解答

常见问题

NotchMuse 支持哪些音乐平台？

目前支持 Spotify、Apple Music、网易云音乐、QQ 音乐和汽水音乐。

需要什么样的 Mac？

NotchMuse 需要 macOS 14 或更新版本，以及 Apple 芯片 Mac。

为什么 macOS 会请求权限？

NotchMuse 需要“自动化”权限读取所选音乐应用的当前曲目和播放进度。菜单栏左侧布局还需要“辅助功能”权限。

NotchMuse 会上传或监听我的音频吗？

不会。应用不会读取或上传音频。为匹配歌词，曲目信息可能会发送给第三方歌词服务提供方。NotchMuse 不需要账户，也不收集遥测数据。

macOS 提示无法打开 NotchMuse 时该怎么办？

官网下载包尚未经过 Apple 公证，首次打开时 macOS 可能需要你确认。请参阅 安装帮助 了解具体步骤。

自动更新如何使用？

从 v0.8.0 开始，在设置 → 通用 → 检查更新中发现并安装签名更新。关闭自动检查后仍可手动检查。如果你正在使用 Beta 3 或更早版本，请手动下载安装一次 v0.8.0。

如何支持 NotchMuse？

在应用内打开支持作者页面，使用微信支付或 USDT，也可以查看 支持页面.

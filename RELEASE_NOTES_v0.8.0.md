# NotchMuse v0.8.0

This release adds an in-app update system with optional automatic checks, a separate local Preview channel for testing, a clearer Settings window on launch and from the Dock, and a Support page. The five existing music players, lyric matching pipeline, display modes, and saved settings remain unchanged.

Users of v0.8.0 Beta 3 and earlier need to install this release manually once. Later signed updates can be offered in the app. This build is ad-hoc signed and not notarized; macOS may require opening it from System Settings > Privacy & Security.

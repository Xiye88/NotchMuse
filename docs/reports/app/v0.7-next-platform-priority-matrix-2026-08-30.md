## Recommendation

`Universal Binary / Intel` 是唯一存在公开、稳定生产路径的候选，但开始前必须
取得 Intel macOS 14+ 真机与真实用户需求。主要工作是双架构 build/sign/DMG，
以及 Status Bar、顶部浮层、多显示器和播放器回归。

QQ Music 虽有官方开发能力，但当前公开能力不提供 macOS client 当前歌曲、
播放状态和进度。NetEase Cloud Music 同样没有验证到稳定公开的 macOS
now-playing API。YouTube Music 官方桌面形态是 Web App，公开 IFrame/Data API
不能读取用户现有 Web App 播放会话。

## Production Boundary

- Private MediaRemote：不接受。
- Accessibility、UI/DOM scraping、窗口标题读取：不接受。
- QQ Music、NetEase 与 YouTube Music 只有出现稳定公开 now-playing API 才重审。
- Apple Music 已完成，不重复研究。

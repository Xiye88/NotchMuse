# NotchMuse 0.3.0 Beta

This is the first GitHub Open Source Beta Release Candidate for NotchMuse.

## Highlights

- Native macOS menu bar lyrics companion for Spotify
- Status Bar and Notch Mode lyrics display
- English and Simplified Chinese interface
- Multiple lyrics providers: LRCLIB, NetEase, LRCMux, QQ Music, Kugou, and Soda Music
- Settings for display mode, width, screen target, color, font size, animation speed, opacity, and launch behavior
- Unsigned DMG package for GitHub beta distribution

## Installation

Download `NotchMuse.dmg`, open it, and drag `NotchMuse.app` into `Applications`.

This beta is unsigned. If macOS blocks launch, Control-click `NotchMuse.app`, choose `Open`, and confirm. If needed, use `System Settings > Privacy & Security > Open Anyway`.

## System Requirements

- macOS 14.0 or later
- Apple Silicon Mac
- Spotify desktop app for macOS

## Known Issues

- macOS Gatekeeper warning is expected because this beta is unsigned.
- Intel Mac is not supported yet.
- Lyrics coverage depends on third-party providers.
- Left Status Bar mode requires Accessibility permission.
- Menu bar organizer apps may hide the NotchMuse icon.

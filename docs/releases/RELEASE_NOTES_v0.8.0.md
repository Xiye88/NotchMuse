# NotchMuse v0.8.0

## What's New

- In-app updates with Sparkle: release notes, download, EdDSA verification, installation, and relaunch. Manual checks remain available with automatic checks off.
- Refined Settings navigation, live previews, window-size persistence, and System / Light / Dark appearance, including the Support window.
- Launch at Login, Dock visibility, menu bar icon controls, and reliable reopening of Settings.
- Status Bar lyrics and four overlay positions: top, above the Dock, left vertical, and right vertical. Custom width, solid/gradient colors, and background controls.
- English and Simplified Chinese; a compact Support page.
- Spotify, Apple Music, NetEase Cloud Music, QQ Music, and Soda Music. Existing matching, provider order, and saved settings are preserved.

### Installation and Updates

Requires macOS 14+ and Apple Silicon. If you're using Beta 3 or an earlier version, install v0.8.0 manually once. Starting with v0.8.0, NotchMuse supports in-app update checks and installation.

This release is ad-hoc signed, not Apple Developer ID notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Do not disable Gatekeeper.

## 更新内容

- 新增 Sparkle 应用内更新：更新说明、下载、EdDSA 校验、安装与重启。关闭自动检查后仍可手动检查。
- 优化设置导航、实时预览和窗口尺寸保存；支持跟随系统、浅色和深色外观，支持页面也随外观切换。
- 开机自动启动、Dock 与菜单栏图标控制，以及可靠的设置窗口重新打开行为。
- 菜单栏歌词及顶部、Dock 上方、左侧竖排、右侧竖排四个位置；可调宽度、纯色/渐变色与背景。
- 简体中文与 English，以及简洁的支持作者页面。
- 支持 Spotify、Apple Music、网易云音乐、QQ 音乐、汽水音乐。保留原有匹配逻辑、歌词来源顺序和已保存设置。

### 安装与更新

需要 macOS 14+ 和 Apple 芯片。如果你正在使用 Beta 3 或更早版本，请手动下载安装一次 v0.8.0。从 v0.8.0 开始，后续版本可以在应用内检查与安装。

本版本为 ad-hoc 签名，尚未配置 Apple Developer ID 公证。首次启动被阻止时，请前往 **系统设置 → 隐私与安全性 → 仍要打开**，不要关闭系统 Gatekeeper。

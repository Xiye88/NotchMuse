## Version Identity Rule Evidence

| 类型 | 安全用途 | 禁止用途 |
| --- | --- | --- |
| Live / Remix / Acoustic / Cover / Radio Edit | marker 不对称时作为冲突保护 | 单独证明正确 candidate |
| Remastered | 只有具体 remaster 身份一致才可比较 | 将任意 remaster 视作等价 |
| OST | 明确专门录音版本时作为冲突 | 仅因 source album 是 soundtrack 就改排名 |
| Deluxe / Anniversary | 记录专辑容器信息 | 直接决定曲目录音身份 |
| feat / with | 完整具名 artist set 一致时辅助审计 | 仅按关键词或主艺人接受 |

当前 candidate album 与 ISRC 覆盖均为 `0`，所以这些字段没有进入决策。

## Ranking Simulator v3

新增 Benchmark-only `ranking_simulator_v3.py`，不导入 Production Matcher。它：

- 排除 insufficient/indistinguishable case 的 accuracy 分母；
- 分开统计 correct、wrong candidate、false positive、unresolved；
- 仅支持 stable-ID/exact-identity dedup；
- 只有两侧 ISRC 都存在时才比较；安全 version marker 只作冲突保护；
  album/Deluxe/Anniversary/OST/feat/with 不单独产生选择。

Ground Truth v1 的 resolved `top/second/neither` 为 `0`，因此 Current 与
Experimental 的 correct/wrong/ambiguity/false-positive **rate 均为 N/A（分母 0）**。
这不是“尚未运行”，而是运行资格检查失败。严格 diagnostic signal 在 50 例中
选择 top `4`、second `3`、unresolved `43`，但这些数字不进入准确率。

结论：Experimental Ranking 没有证明优于 Current，Production Matcher `NO-GO`。

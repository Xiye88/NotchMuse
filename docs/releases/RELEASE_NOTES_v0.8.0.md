# NotchMuse v0.8.0

This release adds in-app update controls, clearer window and Dock behavior, menu bar icon visibility settings, and a compact Support page. Spotify, Apple Music, NetEase Cloud Music, QQ Music, and Soda Music remain supported. Existing lyric matching and saved settings are preserved.

Users of older builds need to install this release manually once. Later signed updates can be offered in the app. This build is ad-hoc signed and not notarized; macOS may require opening it from System Settings > Privacy & Security.

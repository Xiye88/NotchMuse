告别遮挡：为什么你需要更克制的桌面歌词

写代码、剪辑或处理文档时，传统的大字桌面歌词条很容易遮住界面按钮。NotchMuse 把歌词安排在更克制的视觉位置——顶部菜单栏、MacBook 刘海两侧，或支持点击穿透的悬浮浮层。

原生 Swift 打造：流畅自然与低资源占用

NotchMuse 基于原生 Swift 与 AppKit 架构开发，专为 macOS 14+ 与 Apple 芯片打造，轻量运行、静默常驻，不打扰日常多任务工作流。

你可以在设置中调整色彩预设、透明度、显示宽度与动画速度，让歌词与你的桌面融为一体。

极简上手：三步开启网易云歌词同步

  1. 在网易云音乐 Mac 客户端设置中关闭自带桌面歌词条（避免重叠）。
  2. 播放一首歌曲，确认 macOS 播控中心已识别当前曲目。
  3. 打开 NotchMuse 设置，使用“自动检测”或手动选择网易云音乐，并挑选喜欢的显示模式。

歌词同步与曲库匹配说明

NotchMuse 通过公共歌词索引匹配时间轴，支持主流中外曲目的同步展示；当歌词源包含逐字时间戳时，也能平滑呈现逐字推进效果。

常见问题

是否需要关闭网易云音乐自带的桌面歌词功能？

建议关闭官方自带的桌面歌词悬浮条，避免双重遮挡；关闭后仅由 NotchMuse 负责在状态栏或刘海位置静默展示。

哪些歌曲可以正常显示同步歌词？

凡具备公共时间轴歌词的歌曲均可自动同步；部分无时间轴的纯音乐、翻唱或播客内容将显示歌曲名与歌手。

网易云音乐切歌时，歌词反应是否会有延迟？

不会。NotchMuse 持续监听系统音频通道切换事件，曲目变更后自动刷新时间轴。

软件需要网易云音乐授权或输手机号登录吗？

完全不需要。NotchMuse 不干涉你的账户体系，纯粹作为系统层辅助浮层工具运作。

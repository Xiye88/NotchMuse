顶部、Dock，还是菜单栏？

刘海附近

在“刘海模式”中使用靠近顶部的独立浮层，再调整宽度和位置，让歌词适合当前工作布局。

Dock 上方

当视线更常落在下方时，把浮层移到 Dock 上方；显示的仍是所选播放器的同步歌词。

菜单栏内

希望文字直接显示在菜单栏中时，可以选择菜单栏模式。

录屏保留完整桌面，方便判断实际比例与位置。这是已有产品录屏，不是模拟刘海，也不代表在每一种 Mac 型号上分别录制。

设置刘海模式

  1. 在 Mac 上用 Spotify、Apple Music、网易云音乐、QQ 音乐或汽水音乐播放歌曲。
  2. 打开 NotchMuse 设置，确认选择了正确的播放器。
  3. 选择“刘海模式”，通过位置设置把歌词放在顶部或 Dock 上方。
  4. 调整宽度、字号、颜色与背景，让歌词在当前桌面上清楚可读。

可以先用熟悉的歌曲，检查曲目信息与歌词时间是否跟随播放。具体歌曲仍取决于第三方歌词服务的匹配结果。

下载前，先确认 Mac 要求

当前公开版 NotchMuse 需要 macOS 14 或更新版本，以及 Apple 芯片 Mac，不支持 Intel Mac。不确定芯片型号时，可以在 Apple 菜单的“关于本机”中查看。

“刘海模式”描述的是浮层显示方式；菜单栏和 Dock 位置也提供了其他选择。请根据自己的实际屏幕调整，不要把演示画面理解成针对每一种 MacBook 刘海形状分别录制。

专注歌词显示

NotchMuse 专注于工作时的歌词显示，提供位置与外观调整。它不是同时包含计时器、文件暂存和通知中心的综合 Dynamic Island 工具。

如果你寻找刘海应用的主要目的就是看歌词，可以重点检查播放器支持、可读性、位置和歌曲匹配。Spotify 与 Apple Music 的连接步骤，可查看下方对应指南。

常见问题

歌词可以移到 Dock 上方吗？

可以。现有刘海模式演示展示了顶部与 Dock 上方两个位置，可在设置中调整。

它是完整的 Dynamic Island 替代工具吗？

本页介绍的是歌词浮层及其外观、位置设置，不承诺综合刘海工具的其他能力。

Intel MacBook 可以使用吗？

当前公开版不支持，需要 Apple 芯片 Mac 与 macOS 14 或更新版本。

安装与隐私

当前公开版需要 macOS 14+ 与 Apple 芯片，不支持 Intel。官网下载包尚未完成 Apple Developer ID 公证，首次打开可能显示安全提示。请先阅读 安装说明。

应用无需账户，不收集遥测，也不读取或上传音频；为了匹配歌词，曲目信息可能发送给第三方服务。经同意才启用的官网统计与应用本身分开，下载按钮点击不代表安装成功。 隐私与官网统计说明

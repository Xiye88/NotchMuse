How these local LRC tools work

Every conversion runs purely in JavaScript inside your browser tab. No lyric files, subtitles, or text are uploaded to NotchMuse servers or third-party APIs.

  • LRC to SRT: Parses standard [mm:ss.xx] and millisecond [mm:ss.xxx] tags, sorts multi-timestamp chorus lines chronologically, and sets each cue's end time to the next line's start time (with a customizable duration for the final line).
  • LRC Time Shifter: Adds or subtracts milliseconds or seconds from every timestamp tag in the file while preserving metadata tags ([ti:], [ar:], [al:]). Any result below zero is safely clamped to [00:00.00].
  • SRT to LRC & Plain Text: Converts standard SubRip HH:MM:SS,mmm --> HH:MM:SS,mmm cues into compact [mm:ss.xx] lines, or strips all timestamps and indices for clean reading or notes.

Frequently asked questions

Are my LRC or SRT files uploaded to a server?

No. File reading, timestamp math, and file export all happen locally inside your browser using the Web FileReader and Blob APIs.

What happens if a negative time shift goes below 00:00.00?

Any shifted timestamp that would fall below zero is automatically clamped to [00:00.00], and the status bar tells you exactly how many lines were clamped.

Does LRC to SRT support multiple timestamps on one line?

Yes. Repeated chorus lines such as [00:32.00][01:48.50]Line text are expanded and sorted in timeline order before generating numbered SRT cues.

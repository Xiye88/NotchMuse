## Raw Response / Parser Matrix

“丢弃”表示 raw fixture、live response 或解码结构已证明存在，但最终 Candidate /
`LyricLine` 不保存；“未证实”表示本轮没有 raw 证据，不能按常见 API 印象补猜。

| Provider | 已证明的 raw metadata | 当前保留 | 明确丢弃或未证实 |
| --- | --- | --- | --- |
| LRCLIB | id、trackName、artistName、albumName、duration、instrumental、plainLyrics、syncedLyrics、lyricsfile | title、artist、duration、synced lyric | id、album、instrumental、plain/lyricsfile 丢弃；ISRC/release/language 未证实 |
| LRCMux | track ISRC/title/artist/album/duration；source id/name/url；level；line start/end/text | title、artist、duration；ISRC 仅用于脚本冲突保护；start/text | album、source ID、level、line end 不输出；release/language 未证实 |
| NetEase | song id/name/artists/duration；lrc.lyric | ID 驱动 lyric 请求；title、artist、duration、LRC | album、ISRC、release/language 未由当前 fixture 证实 |
| Kugou | song hash/title/artist/duration；lyric id/accesskey/title/artist/duration；KRC content | 两级 ID 驱动请求；title、artist、duration、KRC | album、ISRC、release/language 未证实 |
| QQ | song MID/title/singer/duration；fixture numeric id；LRC content | MID 驱动请求；title、artist、duration、LRC | numeric id 不保存；album、ISRC、release/language 未证实 |
| Soda | track id/name/artists/duration/album；lyric content/type | ID 驱动请求；title、artist、duration、KRC/LRC | album 丢弃；ISRC、release/language 未证实；endpoint 当前 unhealthy |

所有 Provider 最终只返回 `LyricLine(time, text)`。Benchmark 的 candidate evidence
也只持久化 title、artist、duration 和派生 evidence hash；该 hash 不是 Provider
stable ID。candidate album、ISRC、歌词正文和 provider-native ID 因而无法进入
离线 Ground Truth。

# NotchMuse v0.8.0 Beta 3

Build 38, macOS 14+, Apple silicon.

## Changes

- Four lyric positions: top, above the Dock, left vertical, right vertical.
- Clear Solid / Gradient color selection, with 12 solid and 10 gradient presets plus custom colors.
- Fixed solid colors not appearing correctly in Notch mode.
- Background-only opacity, compact background padding, background colors and hover hiding controls.
- Improved Settings mode selection, custom width and horizontal-offset controls.

Spotify, Apple Music, NetEase Cloud Music, QQ Music and Soda Music remain supported. No player, Matcher or Provider-order changes in this release.

## Install

Download `NotchMuse.dmg`, drag NotchMuse to Applications, then open it.
This beta is ad-hoc signed and **not notarized**. If macOS blocks the first launch, choose Done, then System Settings > Privacy & Security > Open Anyway. The DMG includes an installation guide and Privacy & Security shortcut. Do not disable Gatekeeper globally.

## Notes

- Side placements use upright-character columns; arbitrary dragging is not included.
- Side layouts may be less suitable for long English lyrics.
- Private MediaRemote bridge compatibility may change with macOS updates.
- User GUI acceptance, full self-tests and Settings interaction checks passed. Prior releases remain available for rollback.

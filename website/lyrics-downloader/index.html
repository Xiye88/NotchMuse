What is an LRC file and how does it work?
LRC (LyRiCs) is a standard plain-text lyric format that prefixes each line with a timestamp such as [00:15.20]. Compatible audio players read those markers to highlight and scroll lines in sync with playback.
Compared with plain TXT lyrics, synced LRC files work seamlessly across digital audio players (DAPs), car stereos, and local desktop libraries.

        
How to use downloaded LRC lyrics in desktop & portable players
  1. Search for your song above and click Download .LRC File to save a UTF-8 encoded .lrc file.
  2. Rename the .lrc file so it matches your MP3 or FLAC filename exactly (keeping the .lrc extension).
  3. Place the .lrc file in the same folder as the audio track; most local players will detect it automatically.

Frequently asked questions
What is the difference between an LRC file and a TXT file?
An LRC file contains time tags (e.g. [00:15.20]) before each line of lyric text, allowing compatible music players to highlight and scroll the lyrics in sync with the audio. A TXT file contains raw lyric text without timing markers.
Can I use downloaded LRC files on my phone, DAP, or car audio?
Yes. Most dedicated music players (such as HiBy, FiiO, Sony Walkman), Android media apps, and car USB audio systems automatically display lyrics when the .lrc file has the exact same filename and folder as the audio track.
Does this tool download MP3 or music audio?
No. This tool strictly searches and downloads lyric text files (.lrc and .txt). It does not host, process, or download audio streams.
Where does the lyric data come from?
Search results and timing data are fetched in real time from the open community lyric repository LRCLIB.
How does NotchMuse for Mac handle lyrics differently?
If you listen to streaming music on Mac (Spotify, Apple Music, NetEase Cloud Music, QQ Music, or Soda Music), NotchMuse eliminates manual file downloads. It detects the active track through macOS Now Playing and renders live scrolling lyrics automatically around your notch or menu bar.

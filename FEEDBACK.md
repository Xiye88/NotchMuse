# Feedback

Thanks for testing NotchMuse during the public beta.

## Where to report

- Use a **Bug report** issue for reproducible problems, crashes, display bugs, lyrics mismatches, permission trouble, or install issues.
- Use a **Feature request** issue for focused use cases or improvements.

## Useful environment details

Please include what applies:

- macOS version
- Mac model / CPU
- Notch or display setup
- NotchMuse version
- Music service
- Display mode: Status Bar or Notch Mode
- Steps to reproduce
- Expected result and actual result

## Logs, screenshots, and screen recordings

Screenshots, screen recordings, and logs are helpful, but please remove private information first.

Do not submit credentials, access tokens, private account names, personal files, private messages, or unrelated desktop/menu bar details.

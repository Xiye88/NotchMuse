Spotify Lyrics Overlay on Windows

Spotify's built-in lyrics view disappears the moment you switch away from the Spotify window. NotchMuse gives you a dedicated, click-through Spotify lyrics overlay on Windows that stays readable while you code, browse, or play—without stealing mouse focus.

STEP 1

Play in Spotify

Start any track in the Spotify desktop app on Windows 11 or 10. NotchMuse reads track title and timeline directly from Windows SMTC.

STEP 2

Switch to any window

Jump straight into Chrome, VS Code, Figma, or a borderless full-screen game. Spotify can stay minimized in the background.

STEP 3

Lyrics stay pinned & click-through

Enable position lock and click-through so the floating lyrics stay visible while clicks pass through to the window beneath.

Compatible music players

Frequently asked questions

Which Windows versions are supported?

NotchMuse for Windows targets Windows 11 and Windows 10 (64-bit) using native SMTC media integration.

Will the Spotify lyrics overlay block clicks in my browser or game?

No. Once click-through and position lock are enabled, all mouse clicks pass straight through the lyrics overlay to the window underneath.

Does NotchMuse work with MusicBee and foobar2000 on Windows?

They can sync when they publish playback metadata to Windows SMTC. Depending on your player version, you may need to enable that integration.

Looking for macOS instead?

NotchMuse for macOS 14+ (Apple silicon) is available right now on the NotchMuse Home page.
